## 9. 決定済み事項

以下は既存資料上、すでに確定しているため再確認不要です。

- システム名は FocusDigest
- SMTP接続先はGmail
- `.env` 利用は可
- SQLite保存先は `data/app.db`
- ログ保存先は `logs/app.log`
- Dockerでは `./data:/app/data` と `./logs:/app/logs` をホストマウントする
- 手動実行はHTTP APIのみ
- `digest_runs` はメール本文を保存せず、送信結果のみ保存する
- 分野名は `2文字以上50文字以内`、日本語、英字、数字、半角スペース、`-`、`_` を許可する
- DBバックアップは日次1回、14世代保持
- ログは日次ローテーションし、30日保持
- ユーザー向け文言、運用者向け文言、ログ文言、メール本文、APIの `message` は日本語で統一する
- MVPは単一分野、単一配信先
- 技術は Python、FastAPI、APScheduler、SQLite、SMTP、Docker、NewsAPI、OpenAI API
- Web UI、認証、クラウド本番運用、監視基盤、CI/CDはMVP対象外
- APIは `health`、手動実行、最新実行結果取得の3本
- DB中核テーブルは `articles` と `digest_runs`
